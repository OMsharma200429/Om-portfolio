## ⚙️ Run Locally

### 1. Clone the repository

    git clone https://github.com/OMsharma200429/Om-portfolio.git

### 2. Navigate to the project

    cd Om-portfolio

### 3. Install dependencies

    npm install

### 4. Start the development server

    npm run dev

### 5. Build for production

    npm run build
